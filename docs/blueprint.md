# **App Name**: ThrottleUp Training

## Core Features:

- Training Session Creation: Allow trainers to create training sessions with details such as date, time, location, and skill level.
- Training Registration: Enable riders to view available training sessions and register for them.
- Training overview: Display a list of training sessions the rider is registered to attend.

## Style Guidelines:

- Primary color: Dark green (#1B5E20) to evoke nature and the outdoors.
- Secondary color: Gray (#B0BEC5) for backgrounds and neutral elements.
- Accent: Orange (#FF5722) for action items and highlights, inspired by motocross branding.
- Clean and organized layout with clear sections for easy navigation.
- Use icons related to motorcycles, tracks, and training activities.
- Subtle transitions and loading animations to provide feedback during interactions.

## Original User Request:
An app that helps
- trainers to manage motocross and enduro trainings
- riders to register for trainings
